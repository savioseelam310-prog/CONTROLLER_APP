# 🎮 Android PC Controller

Turn your Android phone into a game controller for your Windows PC!

Android PC Controller lets you use your phone as a controller to play PC games, with support for Wi-Fi and Bluetooth connectivity depending on the receiver setup.

## ✨ Features

- 📱 Use your Android phone as a PC game controller
- 🎮 Designed for controlling PC games
- 📡 Wi-Fi connection support
- 🔵 Bluetooth connectivity support, depending on receiver configuration
- 🖥️ Designed for Windows 10 and Windows 11

## 📥 Download

**[Download Android PC Controller](../../releases/latest)**

You can also find the APK file in this repository.

1. Download the `.apk` file to your Android phone.
2. Open the downloaded file.
3. Allow installation from this source if Android asks.
4. Install and launch the app.

Only install APK files you trust.

## 🖥️ Requirements

- An Android phone compatible with the APK
- A Windows 10 or Windows 11 PC
- A Wi-Fi network or compatible Bluetooth connection
- The PC receiver software, if required by your setup

## 🚀 Getting Started

1. Download and install the APK on your Android phone.
2. Start the required receiver software on your PC.
3. Connect your phone and PC using the supported connection method.
4. Follow the connection instructions in the app.
5. Open a compatible PC game and configure its controller settings if needed.

## ⚠️ Important Notes

- The APK is the Android application; it does not necessarily include the PC receiver software.
- Some games may require controller configuration or compatible input drivers.
- Bluetooth availability depends on the receiver implementation.
- This project is provided as-is.
